# Bundled fonts

These Latin variable-font subsets are served locally (no CDN) so the panel works offline.
All three are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org).

| File | Family | Upstream npm package | Original authors |
|---|---|---|---|
| `space-grotesk.woff2` | Space Grotesk | `@fontsource-variable/space-grotesk` | Florian Karsten |
| `inter.woff2` | Inter | `@fontsource-variable/inter` | The Inter Project Authors (Rasmus Andersson) |
| `jetbrains-mono.woff2` | JetBrains Mono | `@fontsource-variable/jetbrains-mono` | The JetBrains Mono Project Authors (JetBrains s.r.o.) |

The Fontsource packages repackage the upstream fonts unmodified apart from subsetting and woff2 compression.
The full licence text is shipped in each package's `LICENSE` file and at the URL above.
